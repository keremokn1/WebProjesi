Web Teknolojileri Projesi - Kişisel Portfolyo

**Proje Durumu:** Sürüm 1.0 (Teslime Hazır) ✅

Bu proje, Sakarya Üniversitesi Bilgisayar Mühendisliği bölümü Web Teknolojileri dersi kapsamında geliştirilmiş, modern web standartlarına uygun, responsive (mobil uyumlu) bir kişisel web uygulamasıdır.
🚀 Proje Hakkında

Proje; temel web teknolojileri (HTML, CSS, JS) ve sunucu taraflı programlama (PHP) kullanılarak oluşturulmuştur. Kullanıcı deneyimini ön planda tutan bir arayüz tasarımı hedeflenmiş ve verilerin hem istemci hem de sunucu tarafında işlenmesi sağlanmıştır.
🛠️ Kullanılan Teknolojiler

    Frontend: HTML5, CSS3, Bootstrap 5 (Responsive Layout)

    İnteraktif Yapı: JavaScript (Frontend Validation, DOM Manipülasyonu)

    Animasyon: AOS (Animate On Scroll) Kütüphanesi

    Backend: PHP (Kullanıcı yetkilendirme ve Login kontrolü)

    Hosting: InfinityFree (Linux tabanlı web sunucusu)

📁 Sayfa Yapısı ve Özellikler

    Hakkında (index.html): Modern bir giriş alanı ve profesyonel tanıtım metni.

    Özgeçmiş (ozgecmis.html): Eğitim bilgileri, geliştirilen projeler ve teknik yeteneklerin listelendiği bölüm.

    Şehrim (sehrim.html): Kocaeli/İzmit'in tarihi ve kültürel değerlerinin (Saat Kulesi, Kocaelispor vb.) tanıtıldığı görsel ağırlıklı sayfa.

    İlgi Alanlarım (ilgi-alanlarim.html): Kişisel hobiler ve detaylı yemek tariflerinin yer aldığı içerik sayfası.

    İletişim (iletisim.html): JavaScript doğrulama (validation) destekli, sunucuya veri gönderen iletişim formu.

    Login (login.html): PHP tabanlı kimlik doğrulama mekanizmasına sahip giriş ekranı.
